# Доработка по независимому аудиту · 21 октября 2026

Цель: сохранить узнаваемую композицию «КОФЕ» и сделать страницу удобной для выбора напитка и заявки на столик. Пользователь одобрил реализацию рекомендаций аудита, вымышленные контакты и содержание.

## Решения

- Карамель, шоколад, молочная бумага; выразительная кофейная композиция и спокойная типографика ниже. Единый иллюстрированный ёж, читаемый текст от 14 px, основные кнопки от 44 px.
- Компактное полное меню с ценой, объёмом, составом и категориями; фирменный раф; подбор по трём вкусам. Данные едины для статической HTML-разметки, карточек, рекомендаций и диалогов.
- Сведения о месте и основные действия доступны с первого экрана, на телефоне есть постоянный переход к меню и столику.
- Заявка после неопределённого ответа проверяется с исходным ключом и данными даже после 503/429 и истечения временного порога. Никаких ложных подтверждений или персональных данных в localStorage.
- Внешняя карта запрашивается только после действия пользователя, рядом всегда остаётся внешний маршрут и повторная загрузка.
- Небольшие модули по сценариям, CSS по разделам, общий контракт валидации, явное доверие прокси. Существующий стек остаётся: TypeScript + Vite, Node.js + SQLite.
- Для локальной работы администратора — статусы заявок и повторные уведомления без публичной административной панели.

## Проверка

Сначала воспроизводящие тесты трёх ошибок аудита, затем исправления. Проверки сборки и типов, HTTP/SQLite-тесты, браузерные сценарии выбора напитка и бронирования, клавиатура, reduced motion, размеры от 320 до 1920 px. Свежий независимый просмотр итогового кода. Публичная публикация и реальные реквизиты не входят в эту локальную доработку.
