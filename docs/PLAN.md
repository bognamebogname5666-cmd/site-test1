# «Семейный Ёж»: план реализации

Цель: выразительный адаптивный лендинг кофейни по приложенному изображению, с галереей, картой и реальным приёмом заявок.

Заказчик разрешил придумать бизнес-данные. Это вымышленный бренд: Москва, Покровка, 27; ежедневно 08:00–22:00. Адрес показывает реальное место на карте, но не подтверждает существование там кофейни. Figma не предоставлена; точное соответствие ей проверить невозможно.

Стек: семантический HTML, CSS, строгий TypeScript, Vite; небольшой Node HTTP-сервер и встроенная SQLite для долговременного хранения заявок. Без клиентского фреймворка и серверных зависимостей.

## Области риска

Временная зона Europe/Moscow; сегодняшний прошедший слот; два одновременных одинаковых запроса; обрыв связи после сохранения; длинные пользовательские значения; отсутствие Telegram; недоступная карта; закрытие диалогов Escape и возврат фокуса; горизонтальное переполнение 320px.

## Структура

`index.html` — семантическая страница; `src/styles.css` — дизайн и адаптация; `src/main.ts` — интерфейс; `src/booking.ts` — форма; `shared/config.json` — бизнес-данные; `shared/validation.mjs` — общая валидация; `server/index.mjs` — HTTP и выдача сайта; `server/bookings.mjs` — SQLite и обработка заявок; `tests/` — проверки; `public/images/` — локальные ассеты.

## Запуск

Локальный проект, без регистрации внешнего сайта. Сервер сохраняет реальные заявки в SQLite; оператор читает их через `npm run bookings`. Telegram опционален. Перед публичным запуском заменить придуманные данные, добавить реквизиты оператора персональных данных, настроить HTTPS, резервное копирование и уведомления.
